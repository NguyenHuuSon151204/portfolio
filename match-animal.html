UNIQUE SELLING POINTS

Integrated power-up system; 'Piggy-bank' reward economy; multiple valid pathfinding patterns.

CHALLENGE

Creating an efficient pathfinding algorithm for large grids that supports multiple connection patterns without dropping frames.

SOLUTION

Developed an optimized connection check with weight-based pathfinding and efficient UI draw call batching.

Game Design Breakdown ●

CORE LOOP

Scan board -> Match tiles -> Clear -> Earn rewards -> Use power-ups.

LEVEL DESIGN STRATEGY

Introductory rules -> Complex constrained paths -> Denser layouts with limited connectivity.

TECH CONSTRAINTS

Optimized 2D asset memory; high-efficiency connection algorithms.

MONETIZATION

Ads integration; power-up purchases; diamond reward loops.

PLAYER EXPERIENCE

Relaxing cognitive flow combined with long-term progression goals.

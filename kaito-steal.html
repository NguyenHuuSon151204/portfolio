Kaito Steal ●

  • Stealth
  • Puzzle
  • WebGL

A unique stealth puzzle game where players control a stretchable hand to grab artifacts while avoiding guards.

Genre: Stealth Puzzle
Platform: WebGL
Year: Apr 2025 - May 2025
Role: Game Designer, Level Designer, Artist
Team Size: 2 (1 Dev, 1 Designer/Artist)
Tools: Unity (C#), Blender

UNIQUE SELLING POINTS

Unique 'Arm Dragging' control scheme; stealth-puzzle hybrid; short, high-impact level sessions.

CHALLENGE

Optimizing Inverse Kinematics for smooth browser performance while creating diverse puzzles under WebGL memory limits.

SOLUTION

Simplified detection systems and strictly managed asset sizes to ensure fast loading and stability.

Game Design Breakdown ●

CORE LOOP

Observe -> Drag hand -> Avoid guards -> Steal -> Complete.

KEY MECHANIC

Stretching hand physics & Time-windowed stealth.

LEVEL DESIGN STRATEGY

Guided progression: teaching drag mechanics in safe zones, then introducing patrol routes, eventually combining obstacles for complex decision making.

TECH CONSTRAINTS

WebGL memory optimization; reduced asset scale; performance-first detection logic.

2.0 The Concept

INITIAL IDEA

Inspired by historical Vietnamese resistance fighters of the 20th century, the game places players in the role of an anonymous hero operating behind enemy lines. The core fantasy is "invisible power" — eliminating threats without ever being seen.

NARRATIVE CONTEXT

Set across 5 regions of Vietnam, each level introduces a unique hero character archetype tied to that region's history — creating emotional investment alongside mechanical progression.

Concept Sketch / Mood Board

UNIQUE SELLING POINTS

Combination of stealth gameplay with puzzle-based progression; culturally-rooted hero characters from different regions of Vietnam with distinct play styles.

3.0 Game Design Document (GDD)

3.1 Core Loop & System Design

CORE LOOP

Observe → Plan → Execute → Escape (or Neutralize).
Players scan the environment using a visible Cone of Vision indicator on enemies, plan a timed approach using environmental distractions, execute the infiltration, and either escape or neutralize the target. Failure triggers instant-replay at the last checkpoint, encouraging experimentation.

PLAYER LOOP

Distraction item → Enemy enters "Investigate" state (3s window) → Player moves → Collect objective → Exfiltrate.

ENEMY AI STATES

Patrol → Alert → Investigate → Chase → Combat. Detection radius scales per level to increase difficulty curve.

3.2 Level Design Flow & Pacing

LEVEL DESIGN STRATEGY

Each level is designed using a 3-node structure: Safe Zone (tutorial beat) → Tension Zone (multiple patrol routes) → Climax Zone (time pressure + puzzle). This ensures pacing never plateaus.

DIFFICULTY SCALING

Patrol routes narrow and intersect across 5 levels. Level 3 introduces synchronized patrol pairs, eliminating predictable safe windows.

3.3 UI/UX Breakdown

UI design prioritizes information clarity: the Cone of Vision overlay and distraction radius arc are always visible to the player, keeping the stealth read intuitive without a HUD tutorial. All screens follow a dark, ink-on-paper Vietnamese art motif.

3.4 Economy & Balancing

No direct economy system. Balancing is done through detection timing windows and patrol speed multipliers. Each level was playtested with a stopwatch — the target "optimal clear time" defines how long each patrol window stays open.

4.0 Technical Design Pipeline

ASSET PIPELINE

2D concept art → Photoshop cleanup → Unity Sprite import. Enemy sprites use a shared atlas to minimize draw calls on WebGL builds.

LEVEL AUTHORING

Levels built in Unity Tilemap. Patrol routes are defined via Waypoint arrays on NavMesh Agents. Distraction zones use trigger colliders with state machine callbacks.

5.0 Key Learnings & Post-Mortem

WHAT DIDN'T WORK

Early patrol AI was too random — playtests showed players felt the game was unfair rather than challenging. Switching to deterministic, readable patrol loops fixed the perception immediately.

WHAT WORKED WELL

The Cone of Vision visual was unanimously praised in playtests — it turned an opaque stealth system into a transparent, learnable challenge. Showing information, not hiding it, is the key lesson.
